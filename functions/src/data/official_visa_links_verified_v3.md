# Verified official visa / immigration-route links — strict v3

**Last checked:** 2026-07-09  
**Scope:** This expands the strict v2 draft. It is still **not a full all-countries directory yet**. I only included links that were opened/validated during this pass and that contained useful visa/permit-specific information. v3 adds more countries while preserving the stricter “no dead or generic-only links” rule.

## Inclusion rule

A link was added only if it met all of these checks:

1. **Official source** — government, immigration authority, foreign ministry, or official public immigration portal.
2. **Visa/permit-specific** — not just a generic immigration homepage.
3. **Useful page content visible** — the page showed a specific visa/permit name and useful details such as eligibility, purpose, duration, fees, application steps, or a list of subtypes.
4. **No dead/blocked pages** — pages that returned internal errors, 403s, unsafe-open errors, or only a generic title without useful visa information were excluded from the main list.

**Validation labels**

- `TEXT-VERIFIED`: the specific visa/permit page opened and showed useful detail.
- `OFFICIAL TYPE-PAGE`: one official page covers several specific visa types/subtypes and the page itself lists the types with useful detail.
- `PATHWAY-VERIFIED`: an immigration pathway page, such as Express Entry or a provincial nominee programme, opened and showed useful details.

---

## Priority order used

This version starts with countries that are popular for immigration or comparatively immigration-route-rich, then moves toward more complex/restrictive systems. Countries are **not ranked as safe/unsafe** here; this is a practical ordering for skilled, study, family, and settlement-route research.
